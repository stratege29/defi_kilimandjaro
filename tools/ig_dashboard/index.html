Playbook croissance (audit expert)

Le ratio qui marche en 2026

Vise 50-60% Reels, 25-30% carrousels, 15% images. Les Reels sont le seul format qui ramène des non-abonnés (≈55% de leurs vues). Rythme régulier : 4-7 posts/semaine.

Les 100 premiers abonnés (amorçage manuel)

  • Commente utile/drôle sur 15-20 comptes/jour dans 3 niches : food ivoirien, nouchi/humour 225, foot africain.
  • Active ton réseau réel (amis, famille, groupes WhatsApp diaspora) — les 30-50 premiers.
  • Poste les Reels foot les jours de match du Mondial (audience ×100).

Hooks & engagement

  • 1re ligne = défi identitaire / controverse chiffrée ("80% se trompent") / tag-bait.
  • Conçois pour le partage en DM (×3-5 vs likes) : "envoie ça à quelqu'un qui…".
  • Carrousels "save-bait" (listes) → sauvegardes = portée durable.
