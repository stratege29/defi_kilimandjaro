# Bibliothèque de prompts Gemini — Ananzè & Mago (toutes variations)

Prompts prêts à coller pour générer le **set complet** des 2 mascottes dans le style
**kawaii figé** (direction A). Concept : `docs/instagram_mascotte_concept.md` · Brief :
`docs/instagram_mascotte_brief.md`.

## Comment l'utiliser (cohérence)
1. Génère d'abord la **pose de référence** (Ananzè « hello » + Mago « hello »).
2. Pour chaque expression, soit tu colles le prompt complet ci-dessous, soit — pour une
   cohérence maximale — tu préfixes : *« Same exact character, same style, palette and
   outline as the reference image, ONLY change the expression/pose: … »* (ou réutilise le
   **même seed**).
3. Génère en **carré 1:1**, **fond transparent** si possible, **sans texte** (ajoute le
   wordmark à la main).
4. Si trop « IA lisse » → ajoute *« hand-drawn, slightly imperfect linework »*.

## Astuces production
- **1:1 + transparent** pour les stickers ; recadrer toute étoile/artefact parasite.
- **Cohérence** : même seed ou « same character as reference, only change… ».
- **Jamais de texte généré** (souvent fautif) → wordmark/labels ajoutés à la main.
- **Garder la malice** d'Ananzè via 1.2 (clin d'œil) et 1.3 (défi) dans le set de base.
- Set minimal recommandé pour lancer : Ananzè {hello, clin d'œil, défi, triomphe, déçu}
  + Mago {hello, si j'avais su, bien joué, choqué, mort de rire}.
