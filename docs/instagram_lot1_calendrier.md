# Instagram @kilimandjaro — Lot 1 : 2 semaines de contenu

> **Contexte : la page démarre à 0 abonné.** Objectif de ce premier lot : exister, donner envie, et amorcer une petite communauté avant le lancement du jeu. Phase **teasing**.
> Handle : `@defi_kilimandjaro`. Visuels fournis dans `docs/instagram_assets/`.

---

## Principes de croissance depuis zéro

À 0 abonné, le hashtag seul ne suffit pas. Ce qui fait grandir une page neuve, dans l'ordre :

1. **Les Reels** — seul format qui touche les non-abonnés massivement. 3/semaine minimum. Les visuels « reel cover » fournis servent de couverture ; le montage vidéo reste à faire (script fourni pour chacun).
2. **Le contenu *enregistrable*** — les carrousels « Le saviez-vous ? » sont conçus pour la sauvegarde (signal fort pour l'algo). On finit toujours par « Enregistre & partage ».
3. **L'engagement provoqué** — les devinettes appellent une réponse en commentaire. Réponds à CHAQUE commentaire la première semaine.
4. **L'amorçage manuel** — partage chaque post dans tes stories perso/WhatsApp, groupes diaspora, et demande à 10-20 proches de suivre + commenter J1. Les 50 premiers abonnés viennent de toi, pas de l'algo.
5. **Les collabs** — dès 100 abonnés, vise des comptes culture ivoirienne / diaspora pour un repost ou un duo Reel.

Rythme : **1 post/jour** (sauf 1 jour off possible) + **stories quotidiennes**. Heures fortes diaspora : **12 h-14 h** et **19 h-22 h** (heure CI/France).

## Notes
- Les **devinettes** sont vérifiées (Attiéké, Foutou) ; les **faits** Zaouli (UNESCO 2017) et Mont Nimba (1 752 m) sont sourcés.
- Les **proverbes** sont des formulations traditionnelles akan/africaines largement attestées.
- Les visuels reprennent exactement la charte « Vert Nuit » du jeu (couleurs + esprit typographique).
- Polices des visuels : Lora (substitut de Fraunces) + Poppins (substitut de Hanken Grotesk). Pour un rendu identique au jeu, on pourra régénérer avec les vraies polices une fois licenciées/installées.
