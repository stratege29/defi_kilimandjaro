# Stratégie d'image — liste stock à télécharger

> Objectif : intégrer ~**1 post photo sur 3-4** pour casser le 100% graphique (les visages = +38% de likes).
> Template prêt : `functions/scripts/photo_card.py` (voile vert/or + texte par-dessus la photo).
> **Critères de choix** : orientation verticale ou avec de l'espace vide (ciel, table, mur) pour poser le texte ; haute résolution (≥ 1080 px) ; **spécifiquement ouest-africain/ivoirien** (évite le générique « afro » ou afro-américain) ; libre de droits, usage commercial.

## Sources
- **Nappy.co** — personnes noires/africaines (gratuit, commercial, sans crédit) : https://nappy.co
- **Pexels** — food, lieux (gratuit, commercial) : https://www.pexels.com
- **Unsplash** — lieux, paysages (gratuit, commercial) : https://unsplash.com
- Plats ivoiriens très spécifiques (attiéké, garba) : si introuvable en gratuit → **iStock/Dreamstime** (payant) ou **photo maison** (le plus authentique).

## Où placer ces photos dans le feed
- **Proverbes** (J5, J12) → photo baobab/savane + citation (superbe en photo+voile).
- **Posts « plat du jour »** (nouveaux) → vraie photo d'attiéké/alloco/garba + énigme.
- **Spotlights ville** → photo Abidjan/Dakar… + accroche.
- **Communauté / relatable** → un visage, une expression (joie, concentration).
- Garde les énigmes animées en Reels ; les photos viennent **en alternance** (1 sur 3-4).

## Workflow d'intégration
1. Télécharge les photos choisies.
2. Dépose-les dans `docs/instagram_assets/photos/` (crée le dossier).
3. Dis-le moi (ou liste les fichiers) → je génère les cartes « photo + voile » avec le bon texte/pack et je les ajoute à la file de publication.

> Démo du rendu : `docs/instagram_assets/photo_demo/` (sur images placeholder — tes vraies photos donneront un résultat bien plus riche).
